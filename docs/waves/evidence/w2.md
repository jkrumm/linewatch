## What changed

- Deps: `basalt-ui` 2.8.1, `@tanstack/charts` 1.1.0, `d3-scale` 4.0.2, `@mantine/*` ^9.7.0 plus
  `modals`/`notifications`/`spotlight`, `shiki` + `@shikijs/{langs,themes}` ^4.5.0, `react-markdown`
  ^10.1.0 (doctor `subpath-peers` for `basalt-ui/content`), `@tanstack/react-query` ^5.104.0,
  `oxlint` 1.87.0 exact (1.88.0 is inside the 3-day release-age cooldown; the preset floor is 1.87).
  Removed: nine `@visx/*`, `motion`, `remend`, `remark-gfm`, `zod` (none imported from `src/`).
- Managed layer: `basalt-ui sync` (rules, skills, `web/AGENTS.md` block, manifest). Its scaffold
  `src/lib/nav.tsx` was deleted — a one-page, shell-less app has no nav (Wave 3 confirms).
- tsconfigs extend `basalt-ui/configs/tsconfig.react-app.json` / `tsconfig.base.json`. The preset adds
  `exactOptionalPropertyTypes` and `noPropertyAccessFromIndexSignature`; real fixes: `Stat` optionals
  widened with `| undefined`, conditional spreads on Mantine props, typed `*.module.css.d.ts` for the four
  consumer CSS modules.
- Wiring: `main.tsx` → `<BasaltProvider router>`; `lib/router.ts` → `createBasaltRouter({ routeTree })`
  (its defaults already carry `defaultPreload: 'intent'`, `defaultPreloadStaleTime: 0`, 30 s `staleTime`,
  no refetch on focus, so `lib/query-client.ts` is deleted); root route on `BasaltRouterContext`.
  Telemetry sink not wired (optional; this repo exports no OTel).
- Imports: `VX` → `basalt-ui/tokens`; `createSearchStore`/`field` → `basalt-ui/state`; `PageBar.actions`
  → tuple with the live chip as `primary: true`.
- `dashboard-section.tsx`: ref write moved from render into an effect (new `react(refs)` error).
