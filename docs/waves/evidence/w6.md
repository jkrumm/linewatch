## basalt friction

1. A `Date` x scale spans the data's own extent, with no x-domain prop, so a run series (first run
   → last run) cannot line up under the bucketed charts (the whole window). The shared cursor finds
   the right instant at a different x. An `xDomain` / window prop would fix it.
2. Rows 94–98 and 89/90/92/93: nothing changed in 2.9.1 for the paths this wave touches; the
   `legend: false` while-pending workaround stays (row 89 unfixed).
3. `Sparkline` takes no width callback and exposes no measured width, so per-cell pooling is a fixed
   ceiling.
