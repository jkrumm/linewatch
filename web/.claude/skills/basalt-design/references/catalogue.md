# Encoding catalogue

Shipped composites: `StatCard`, `ChartCard`, `Section`, `WidgetHeader`, `BasaltDataTable`, `EmptyState`. Imports: chart kinds and `ChartCard` from `basalt-ui/charts`, `BasaltDataTable` from `basalt-ui/table`, the rest from `basalt-ui`. A gap is reported, never hand-rolled. The reviewer cites this file for Expression 1: the data's shape and the encoding used must match a row here.

## 1. Is it even a chart?

Run this first. A "yes, chart" answer sends you to § 2.

| The data is                       | Not this         | Use                                                     |
| --------------------------------- | ---------------- | ------------------------------------------------------- |
| One current value                 | A one-bar chart  | `StatCard` (`stat-tile.md`)                             |
| A handful of headline numbers     | A grouped bar    | `StatGroup variant="strip"` or a row of `StatCard`      |
| One ratio against a limit         | A two-slice pie  | `Meter` with a target tick                              |
| More than ~7 meaningful classes   | More colours     | `BasaltDataTable`                                       |
| Fewer than 4 points               | A line           | `StatCard`                                              |
| 3–10 target-vs-actual metrics     | A bar per metric | A grid of `Meter`s with `target` (basalt's bullet form) |
| A few regions compared            | A choropleth     | `Bars` in a `ChartCard`                                 |
| A set of points (sites, stations) | A map of dots    | `BasaltDataTable`                                       |

| Committed vs forecast                                                          | Two segments, the forecast lighter, a tick and a caption at the boundary                                                                                                                                                                                                         | `Meter` `segments`, `forecastCaption`                                                             | Two cards                                                                |
| Headline ratio where the shape is the message                                  | Ring, value centred, one per row                                                                                                                                                                                                                                                 | `Meter shape="ring"`                                                                              | A donut plus a total card                                                |
| Reading in named bands (low / ok / high)                                       | Zoned bar with the reading as a marker; each zone names its `short` label for a narrow track; `ticks` mark cut-offs or a window mean                                                                                                                                             | `Meter` `zones`, `ticks`                                                                          | Colour-only thresholds                                                   |

| Value over time                                                                | Line; stacked area for parts of a total                                                                                                                                                                                                                                          | `Lines` / `StackedArea` in a `ChartCard`                                                          | A bar per day                                                            |
| Spend over a period against a budget                                           | Cumulative line against the budget line; the forecast end labelled with its figure and date, the budget crossing labelled. Strip form: `Meter` with the reading at the fill end and the target figure on the tick via `caption`                                                  | `Lines` + `refLines` in a `ChartCard`; `Meter` `target`, `ticks`                                  | A daily bar per day; an unlabelled forecast                              |
| Compare categories                                                             | Bars                                                                                                                                                                                                                                                                             | `Bars layout="grouped"` in a `ChartCard`                                                          | A pie                                                                    |

| Distribution as a card's subject                                               | One bar per bin, x labelled with the bin range ("€0–50"), y axis optional                                                                                                                                                                                                        | `Bars` in a `ChartCard`                                                                           | A mean alone; an axis-less histogram                                     |
| Status over time                                                               | Band strip; heat grid for daily data                                                                                                                                                                                                                                             | `BandStrip` / `Heatmap` (`basalt-ui/charts`)                                                      | A table of dates                                                         |
| Categorical status per cell (up, degraded, down)                               | Flat status fills; a glyph on warn and bad, never hue alone                                                                                                                                                                                                                      | `Heatmap` `states` with a `tone` each, no hex; `BandStrip` `glyph`                                | A hue-only grid                                                          |
| A set of KPIs about one record                                                 | One joined surface, cells split by hairlines                                                                                                                                                                                                                                     | `StatGroup variant="strip"`                                                                       | N unrelated cards                                                        |
| Many rows, several attributes                                                  | Table, right-aligned figures                                                                                                                                                                                                                                                     | `BasaltDataTable` (`basalt-ui/table`)                                                             | Cards per row                                                            |
| Record facts in a table row                                                    | Cell kinds: entity (avatar + name, no wrap), status chip, right-aligned figure, relative time, inline meter                                                                                                                                                                      | `BasaltDataTable` column `meta.kind`                                                              | Text in every cell                                                       |
| A geographic field: a raster or grid of values over an area, read as a pattern | A map canvas filling its card flush (the Mantine flush card variant), with a key rail at its edge (beside it or overlaid): the colour ramp, its unit and 3–5 labelled stops; the time scrubber and any legend float over the canvas as panels, whose radius steps down by itself | The map library's canvas in that card; `height: var(--basalt-main-content-h)` for a page-high map | A choropleth of a few regions; a point set; a ramp with no unit or stops |
| Work items by status (columns with counts)                                     | Columns with a count each, cards inside                                                                                                                                                                                                                                          | `Board` (`basalt-ui`)                                                                             | A table with a status column; a chart of counts                          |
| A record, a pending decision, an entity or a list row                          | The recipe in `recipes.md`                                                                                                                                                                                                                                                       | `StatGroup`, `EventList`, `PageAside`, `PageSummary` (`basalt-ui`)                                | A card per section; a hand-rolled facts layout                           |
| Nothing yet / failed                                                           | Why and what to do                                                                                                                                                                                                                                                               | `EmptyState`, or the component's own `query` state                                                | "No data"                                                                |

Sections that sit side by side use one title size; a `Section` beside a `ChartCard` does not step a size down.

A `Section` has no surface of its own. A lone `BarList`, `EventList` or `Meter` in a grid beside `ChartCard`s goes in a `ChartCard` (`placeholderHeight="content"`), so the row reads as one surface level; a `Section` holding several figures or cards stays flat.
